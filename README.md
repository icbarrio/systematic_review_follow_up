
# Systematic review follow-up

<!-- badges: start -->
<!-- badges: end -->

This repository contains data and code to run the analysis for an update of the systematic review on herbivore diversity (Barbero-Palacios et al. 2024). The original search was conducted in 2021. An updated search was conducted in the fall 2026.

## Reference
